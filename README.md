#### **打开labelstudio**
复制链接，到浏览器搜索
![images/1.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/1.png)
注册账户(邮箱无需认证，随意即可)
![images/2.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/2.png)
#### **进入项目**
在首页点击Recent Projects栏右边的View All
![images/3.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/3.png)
找到相应的项目，点击进入
![images/4.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/4.png)
点击进入需要打标的视频项目
![images/5.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/5.png)
![images/5.5.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/5.5.png)
#### **如何打标**
拖动进度条，到达相应位置 <br>
![images/6.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/6.png) <br>
选择相应label <br>
![images/7.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/7.png) <br>
在末端帧点击 <br>
![images/8.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/8.png) <br>
在右边Info中，编辑frame范围 <br>
![images/9.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/9.png) <br>
完成后在下方点击Submit/Update保存 <br>
![images/10.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/10.png) <br>

#### **视频是否异常**
异常视频可能是：没有操作机械臂、不是做叠毛巾的任务
若视频异常则点击1，反之
![images/11.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/11.png)

#### **如何导出数据**
在项目页面点击Export
![images/12.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/12.png)
选择JSON
![images/13.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/13.png)
点击下方Export导出文件
![images/14.png](https://raw.githubusercontent.com/vvvvaxs/labelstudio/main/images/14.png)
