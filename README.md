#### **打开labelstudio**
复制链接，到浏览器搜索
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/1.png)
注册账户(邮箱无需认证，随意即可)
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/2.png)
#### **进入项目**
在首页点击Recent Projects栏右边的View All
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/3.png)
找到相应的项目，点击进入
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/4.png)
点击进入需要打标的视频项目
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/5.png)
#### **如何打标**
拖动进度条，到达大致位置
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/6.png)
选择相应label
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/7.png)
在末端帧点击
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/8.png)
在右边Info中，编辑frame范围
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/9.png)
完成后在下方点击Submit/Update保存
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/10.png)

#### **视频是否异常**
异常视频可能是：没有操作机械臂、不是做叠毛巾的任务
若视频异常则点击1，反之
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/11.png)

#### **如何导出数据**
在项目页面点击Export
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/12.png)
选择JSON
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/13.png)
点击下方Export导出文件
![images/1.png](https://github.com/vvvvaxs/labelstudio/blob/main/images/14.png)
